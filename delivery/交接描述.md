### B 的 5 分钟快速上手

```python
# 1. 加载 Q1 100 条样本（域外测试集）
import sys
sys.path.insert(0, 'delivery/00_common/code')
from src.data_loader import load_q1_features
data = load_q1_features('delivery/00_common/data/q1_features_combined.pkl')
# → text: (100, 50, 768)  audio: (100, 50, 74)  vision: (100, 50, 35)

# 2. 加载模型并做推理
import torch, sys
sys.path.insert(0, 'delivery/for_B/code')
from baseline_model import LateFusionModel
model = LateFusionModel(text_dim=768, audio_dim=74, vision_dim=35, hidden_dim=320)
model.load_state_dict(torch.load('delivery/for_B/models/latefusion_seed2024.pt', map_location='cpu'))
model.eval()
```

### C 的 5 分钟快速上手

```python
import sys
sys.path.insert(0, 'delivery/for_C/code')
from video_utils import (
    locate_video_file,           # sample_id → 视频路径
    get_video_metadata,          # 读视频元数据
    extract_key_frames,          # 均匀抽关键帧
    extract_frame_at_timestamp,  # 在指定秒抽一帧
    timestamp_to_frame,           # 秒 → 帧号
    frame_to_timestamp,          # 帧号 → 秒
    map_modality_timestep_to_original_time,  # timestep → 原始秒数
)

# 定位视频
VIDEO_BASE = '/your/path/附件1-数据集原始多模态样本/MOSEI数据集部分原始视频-100条'
sample_id = '-3g5yACwYnA$_$13'
video_path = locate_video_file(sample_id, VIDEO_BASE)

# 读元数据（不用 ffmpeg）
meta = get_video_metadata(video_path)
# → {'duration': 8.767, 'fps': 30.0, 'total_frames': 261, 'width': 1280, 'height': 720, 'codec': 'h264'}

# 抽取关键帧做可视化
frames = extract_key_frames(video_path, n_frames=5, mode='uniform')
# → [{'timestamp': 0.0, 'frame_idx': 0, 'image': array(...), ...}, ...]
```

## 五、B 和 C 共享的基础设施

B 和 C 都需要的文件，统一放在 `delivery/00_common/`：

```
delivery/00_common/
├── data/
│   ├── q1_features_combined.pkl         ← 合并特征（直接 load 使用）
│   ├── q1_feature_summary.csv           ← 100 条摘要表
│   └── single/                           ← 100 个单样本 pkl
├── code/
│   ├── src/data_loader.py               ← 统一数据加载接口（B 和 C 都必须用这个加载 Q1 数据）
│   └── src/feature_extractor/aligner.py ← 时序对齐（B 做推理时需要，C 做可视化时需要）
└── docs/
    ├── feature_spec.md                  ← 字段规范（必读）
    ├── q1_decisions.md                  ← 8 个关键决策
    └── versions.txt                     ← 环境版本
```

⚠️ **不要直接用附件 2 的数据拼接 Q1 100 条训练**（text_bert 维度顺序相反，audio/vision 数值分布不同）。

Q1 100 条的正确用法：
- 成员 B：**域外测试集**，验证附件 2 训练的模型是否过拟合
- 成员 C：**可视化素材**，生成可解释性 figure
