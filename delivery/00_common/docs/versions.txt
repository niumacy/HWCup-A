## 已知不兼容项（需要适配）

1. **transformers 4.30 → 4.46**：`BertModel.from_pretrained(output_hidden_states=False)` 参数仍然兼容；但 `output_attentions` 的返回值结构有微小变化，本项目未使用。
2. **librosa 0.10 → 0.11**：`librosa.feature.spectral_contrast` 的返回 shape 可能因版本不同而变化，已在代码中显式 `mean(axis=0, keepdims=True)` 适配。
3. **torch 2.0 → 2.4**：API 完全向后兼容，无需修改。
4. **Pillow 7.0.0** ⚠️：相对较旧，`ToPILImage` 在某些 resize 行为上与新版略有不同，但当前 ResNet18 预处理不受影响。

## 复现命令（一键）

```bash
# 1. 准备 Python 环境
cd /mnt/data2/home/chenyu/HuaWeiCup/huaweibei-E
pip install -r requirements.txt
# 注: pip 真实装的版本可能略高（如 transformers 4.46 而不是 4.30），
#     但 API 兼容。详见本文档上方表格。

# 2. 下载预训练权重（首次运行自动）
python3 -c "from transformers import BertModel; BertModel.from_pretrained('bert-base-uncased')"
python3 -c "import torchvision.models as m; m.resnet18(weights=m.ResNet18_Weights.IMAGENET1K_V1)"

# 3. 全量提取（~2 分钟）
python3 scripts/extract_features.py

# 4. 验证
python3 -c "
import pickle
d = pickle.load(open('data/processed/features_q1/q1_features_combined.pkl','rb'))['all']
print('text:', d['text'].shape, 'audio:', d['audio'].shape, 'vision:', d['vision'].shape)
"
```
